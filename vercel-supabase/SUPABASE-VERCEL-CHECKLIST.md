# Checklist de publicación

- [ ] Ejecuté `supabase/schema.sql`.
- [ ] Creé el usuario administrador en Supabase Auth.
- [ ] Cambié su perfil a `role='admin'`.
- [ ] Configuré las cinco variables en Vercel.
- [ ] Confirmé que `SUPABASE_SERVICE_ROLE_KEY` no comienza con `NEXT_PUBLIC_`.
- [ ] Subí solamente el contenido de `vercel-supabase` a GitHub.
- [ ] Ejecuté un deployment.
- [ ] Inicié sesión con el administrador.
- [ ] Importé los históricos del funnel.
- [ ] Importé BDC.
- [ ] Actualicé Industria con el ZIP del INEGI.
- [ ] Creé los demás usuarios desde la plataforma.
- [ ] Probé crear, editar y eliminar un registro.
- [ ] Confirmé el cambio en Supabase Table Editor.
